# v9 股票策略扫描与回测系统（PySide6 桌面版）

本系统为本地股票策略工具：对接本地部署的 `stockdb` 数据服务，全市场扫描行情与基本面，按 **13 大 v9 策略**硬条件筛选，对命中股票做 **14 因子评分**并**按综合分倒序**展示；同时内置 **历史回测引擎**，可对策略/因子/参数做批量挖掘与验证（已通过 6 轮 × 10 组回测挖掘出 6000 元小资金场景的最佳策略与参数）。

## 目录结构

## 运行环境

- Python 3.13（3.13.x 已验证）
- PySide6（`pip install PySide6`）
- pandas / requests / numpy
- 本地数据服务：`free-stockdb-windows`（含 `stockdb.exe`、`数据更新.exe`、`pybao/stock_sdk.py`）

## 部署步骤

### 1. 安装数据服务（stockdb）

在 `free-stockdb-windows` 目录中：

1. 运行 `数据更新.exe`，自动下载最新行情数据（首次需等待同步完成，中途不要关闭）。
2. 打开 `stockdb.exe` 启动数据服务（默认监听 `127.0.0.1:7899`）。

### 2. 注册 stock_sdk 到 Python

将 `pybao` 目录（内含 `stock_sdk.py`、`zhibiao.py`、`stockdb.pyd`）注册进 Python 搜索路径：

```
pip 无法安装时，在 Python 的 site-packages 目录新建 pybao.pth，内容为 pybao 的绝对路径。
```

或直接运行 pybao 目录下的 `安装.py`。

验证：

```python
from stock_sdk import rd
print(rd.get('股票代码'))   # 应返回股票列表
```

### 3. 安装项目依赖

```bash
pip install PySide6 pandas requests numpy
```

### 4. 启动程序

```bash
python main.py
```

### 5. 运行单元测试（可选）

```bash
python -m pytest tests -q        # 75 个用例，验证撮合/择时/本金自适应/UI 默认值/扫描优化/共享筛选链/全量回测/时间窗口
python backtest_mine.py          # 参数挖掘脚本（按需修改阶段配置后运行）
```

## 使用说明

1. **策略**：下拉框选择要扫描的策略（如 v9A2 龙头趋势）；选择「全部策略」则对所有策略统一扫描，命中任一策略即入选。推荐主用「综合因子策略 factor_default」（可迭代编辑），回测挖掘证明其远优于任一 v9 硬条件策略。
2. **候选池上限**：默认 300，仅在**在线数据可用**时生效——扫描先做全市场技术面粗排，取分数前 N 只做在线数据精筛（在线基本面/资金流查询较慢，该值控制精筛规模）。在线数据不可用（接口返回空）时自动切换纯本地评分，**全量精筛、不再截断**，避免漏掉综合分靠后但策略命中的股票。
3. **开始全量扫描**：后台线程执行，进度条与状态实时显示。完成后结果表格按综合分倒序排列。
4. **表格列**：代码 / 名称 / 综合分 / 涨跌幅 / 收盘 / 成交额 / 换手 / 量比 / 主力净流入 / 风控提示。
   - **命中策略**（分是分，参数是限制）：综合分 ≥70 标红（强势接力）、60-69 标橙（情绪接力）、<60 灰。
   - **未命中**：参数限制通过（不追高 ≤6% 且大盘过滤通过）标绿（合格观察池）；参数限制未通过（当日涨幅 >6% 或市场弱势）标灰，详情窗口注明原因。
5. **点击任意行**：右侧显示该股 K 线图（含 MA5/10/20/60 均线）与 14 因子得分明细。
6. **停止**：随时中止扫描。

## 评分体系

14 因子覆盖：趋势结构、均线系统、量能活跃、主力行为、DDE 大单、动量指标、估值水平、市值弹性、流动性、财务质量、资金流等。权重归一化后换算为 **0-100 分**（默认 50 分中性基准），综合分越高代表强势接力概率越高。

## 回测系统

「回测管理」页签支持对当前策略配置一键历史回测：

- **撮合规则**：按 100 股整数手买入，现金不足一手则跳过；单边费率 0.05%（含滑点）。
- **大盘择时**：全池等权指数跌破其 20 日线时跳过买入（空仓等待）；`strong` 模式额外要求 20 日线上行，挖掘证实 strong 显著优于仅站上。
- **卖出规则**：止损 / 止盈 / 持有到期 / 定期重评 / 期末平仓。
- **不追高**：调仓日当日涨幅超过阈值（%）的股票跳过买入。
- **v9 候选排序**：v9 硬条件命中后按本地可回测因子综合分排序择优买入（原为字典序随机，属策略层优化）。
- **持仓数随本金自适应**：每只持仓至少保留约 600 元预算（≈1 手低价股），防止小资金 + 大 TopN 导致多数标的一手都买不起而实际空仓。
- **与扫描共用同一套筛选代码**：行情过滤 / 指标过滤 / 策略命中 / 不追高 / 大盘限制全部由共享模块 `screen_common.py` 实现，回测与扫描只是数据时点不同（`screen_common.evaluate_buy` 为统一判定入口）。回测默认应用与扫描界面默认一致的筛选条件（主板 + 非ST），在线数据过滤因无历史数据按"缺失放行"处理。
- **全量回测**：标的池新增「全A（全量）·逐日历史选股」，覆盖全部 A 股不抽样（`max_codes=0`），与抽样共用同一套判定代码，可对比抽样/全量效果；全量耗时显著增加，建议先用抽样快速验证再跑全量。
- **时间条件**：
  - `strategy_data.py` 提供 `shift_days` / `shift_months` / `calc_window_start` / `calc_backtest_pre_start` 统一计算时间窗口。
  - **扫描页**：可设置「扫描截至」日期（默认最近交易日）与「数据窗口」（3个月/6个月/1年/2年），支持历史截面扫描与不同长度指标窗口。
  - **回测页**：可设置「区间长度」（30/60/120/250/500 个交易日或自定义）与「预热天数」（默认 60）。选择区间长度后起始日期按结束日期自动倒推；自定义时恢复手动输入。

### 回测挖掘结论（6000 元小资金场景）

共执行 6 轮 × 10 组回测（每轮 30s，覆盖策略基线、因子权重、引擎参数、组合验证），结论如下：

1. **13 个 v9 硬条件策略全部弱于 factor_default**：最好为 v9Core / v9Stable（约 +1.3%），但全年仅 8~12 笔交易（命中率过低），v9Tech 零信号。v9 仅适合做扫描筛选，不适合直接回测交易。
2. **因子权重均匀即为最优**：10 组权重组合（动量3x / 趋势3x / 量能3x / 均线3x / 低波动3x / 双因子 / 三因子共振…）均不如均匀权重，因子多样性价值大于单因子强化。
3. **小资金需降低交易频率**：6000 元下持有 15 天 + 不追高 6% + TopN 10 显著更优（+34.19%）；但该低频偏好为小资金专属——100 万大资金对照下低频反而失效（+3.77% vs 高频 +22.66%，后者 372 笔交易统计更可靠）。
4. **大盘强过滤、买入门槛 55、每 2 日重评、止损 -12% / 止盈 +20%** 经多轮验证保持最优。

### 最佳策略与参数（已设为引擎与界面默认值）

> 参数限制同样在**扫描端**生效：不追高 6%（当日涨幅超 6% 不推荐）与大盘强过滤（全池等权指数低于 MA20 或 MA20 走平时不推荐）作为资格限制应用，综合分仅用于排序与强度分档。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 最佳策略 | `factor_default` | 14 因子综合评分，回测 +34.19%（区间大盘 -9.36%，超额 +43.5%） |
| 初始资金 | 6000 | 小资金实盘场景 |
| 买入 TopN | 10 | 6000 元下最优；引擎按每只 ≥600 元预算自动收缩 |
| 持有天数 | 15 | 小资金低频持有，减少摩擦与噪声 |
| 买入门槛分 | 55 | 低于该综合分不买 |
| 重评周期 | 2 日 | 每 2 个交易日重评一次 |
| 止损 / 止盈 | -12% / +20% | 单笔风控 |
| 不追高 | 6% | 当日涨幅超过 6% 不买 |
| 大盘过滤 | 强过滤 | 指数 > MA20 且 MA20 上行 |

> 回测区间为最近 120 个交易日全 A（400 只采样）等权回放，结果含手续费与滑点。小资金样本量较小（约 30 笔），建议以回撤与盈亏比为主要参考，收益数值仅供参考。

## 已知说明

- 全量扫描（3000+ 只）约 **3-5 分钟**：先做「本地因子粗排 → 在线精筛」两步（候选池上限默认 300，仅在在线数据可用时截断；在线不可用时自动切换纯本地评分并**全量精筛不截断**）。原来 3 小时的主要瓶颈是「在线数据逐只请求 + 每只重复计算技术指标」，现已修复。
- 单次回测（400 只采样、最近 120 个交易日）约 30-50 秒，在「回测管理」页签运行；v9 策略因命中率低耗时略长。
- 回测是**历史逐日重放**：v9 硬条件依赖在线因子（资金流/基本面）时无信号属正常现象，本地因子策略（factor_default）回测最完整。
- 数据日期范围在 `strategy_data.py` 的 `START` / `END` 常量，收盘后更新数据服务即可续用。
- 数据服务未启动或数据未同步完成时，扫描会报错；请先确认 `127.0.0.1:7899` 可访问且 `rd.get('股票代码')` 有返回。
- 本程序需要先加载 `stock_sdk` 再加载 PySide6（`main.py` 已按此顺序导入），否则 PySide6 的签名钩子会与 `stockdb.pyd` 冲突。
